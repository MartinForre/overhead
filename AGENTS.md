# Overhead contributor guidance

## Localization

- When adding or changing user-facing text, include Bokmål (`nb`) and Nynorsk (`nn`) translations in `apps/shared/norwegian.js` under the English source string. This includes settings labels, status messages, and accessible names.
- For theme names, use the English display name from `apps/shared/settings-schema.js` as the translation key. Check the affected UI in English, Bokmål, and Nynorsk, including switching languages without reloading.
