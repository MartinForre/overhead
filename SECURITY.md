# Security policy

Overhead is designed for a trusted local network. The Companion can change settings on the shared server, so keep the service on the local network and avoid forwarding port 8000 to the internet.

## Report a vulnerability

Use GitHub’s private reporting form when the repository’s **Security → Advisories** page offers **Report a vulnerability**. Otherwise, open an issue asking for a private contact channel and leave the vulnerability details out of the public post. [Security advisories](https://github.com/MartinForre/overhead/security/advisories) · [GitHub Issues](https://github.com/MartinForre/overhead/issues)

In a private report, include the affected build or commit, the platform and installation method, what is affected, and enough information for a maintainer to confirm the issue. Remove secrets and personal data from any attachments.
